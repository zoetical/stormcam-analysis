# Storm Camera 产品深度分析

基于 **1,215 条 App Store 用户评论**（中国区 1,170 条 + 美国区 45 条）的数据驱动分析，以产品经理视角拆解飓风相机的产品现状、用户反馈、竞品格局、国际化洞察与迭代策略。

**在线查看 →** [stormcam-analysis.vercel.app](https://stormcam-analysis.vercel.app)

---

## 这个项目是什么

这是一份完整的产品分析报告，最终呈现为一个可交互的单页数据看板。

分析覆盖 7 个维度：
- **评分数据** — 分布与月度趋势，识别 v1.4.0 引发的 3 月评分暴跌
- **用户反馈** — 15 个类目按 P0-P3 优先级排列，量化痛点
- **版本时间线** — 半年 25 个版本的迭代节奏与里程碑
- **需求追踪** — 35 项用户需求的解决进度（已解决 / 部分 / 未解决）
- **竞品对比** — 飓风相机 vs Blackmagic Camera vs Kino 的功能矩阵
- **国际市场** — 美区评论分析、跨市场需求对比、国际化路线建议
- **行动建议** — 短 / 中 / 长期产品路线图

## 怎么做的

整个过程是**人机协作**完成的：

1. **数据采集** — 用 AI 辅助脚本批量抓取 App Store 全部 1,170 条用户评论及完整版本更新日志
2. **数据清洗与结构化** — AI 协助将非结构化的评论文本分类、打标、提取关键信息（情感倾向、功能提及、版本关联）
3. **产品分析** — 以产品经理视角，与 AI 协作完成多维度分析：识别核心痛点、量化需求优先级、梳理版本与需求的映射关系、竞品功能对标
4. **可视化呈现** — 将分析结论转化为交互式数据看板，支持筛选、动画、数据钻取

## 技术栈

纯前端，零依赖：

- HTML / CSS / JavaScript（Vanilla，无框架）
- SVG 数据可视化（趋势图、进度环、图标系统）
- Intersection Observer 驱动的滚动动画
- 部署于 Vercel，GitHub 推送自动部署

## 设计风格

参考飓风相机 App 本身的 UI 语言：

- 纯黑背景 `#000`，薄荷绿 `#34c7a9` 强调色
- iOS 原生风格的圆角卡片与分组列表
- 极简线条图标，无 emoji
- 响应式布局，移动端可用
