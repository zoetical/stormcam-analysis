### 核心功能
1. **Apple Log 直出 + 实时 LUT 预览** — 「所见即所得」的电影感拍摄
2. **专业手动控制** — ISO、快门、白平衡、曝光补偿
3. **影调系统（v1.4.0+）** — 标准色彩空间也支持影调，全机型可用
4. **动态图/实况照片** — 短视频片段 + Live Photo 拍摄
5. **48MP 高分辨率拍照（v1.4.0+）** — 根据设备能力
6. **多级防抖** — 标准 / 电影级 / 极致
7. **OpenGate 拍摄** — 全像素利用
8. **批量导出** — v1.1.7 加入，持续优化中

### 产品生态
飓风相机不是一个孤立产品，它嵌入在影视飓风的内容生态中：
- **飓风课堂**：《玩转 Apple Log》课程，购课含 Pro 版兑换
- **闪电分镜**：前期策划工具（同一开发商）
- **飓风工具箱**：影视工具集合（同一开发商）
- **飓风素材库**：4K/8K素材交易平台

## 五、产品经理行动方案

### 短期（1-2个版本）
1. **上线 LUT 浓度滑块** — 解决最高频需求
2. **添加直方图** — 缩小与BMC差距
3. **"一键存入相册"导出快捷方式** — 优化最常用操作
4. **Crash 监控体系建立** — 数据驱动稳定性

### 中期（3-6个月）
1. **半自动曝光模式（S优先/A优先）** — 提升可玩性
2. **自定义 LUT 导入** — 功能性里程碑
3. **拍照模块完善（裁切、更多比例）** — 减少用户切换App
4. **定价策略统一 + 权益声明规范化** — 消除信任危机

### 长期（6-12个月）
1. **iPad 适配** — 新用户群
2. **LUT 社区 / 影调市集** — 商业化+生态
3. **AI 辅助功能**（智能调色、场景识别）— 差异化
4. **与闪电分镜的深度联动** — 生态协同
